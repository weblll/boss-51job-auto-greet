# Boss / 51job 自动投递助手

Chrome + Tampermonkey 用户脚本，当前版本 **2.16.3**，由 **刘雷雷（weblll）**维护。

[项目仓库](https://github.com/weblll/boss-51job-auto-deliver) · [问题反馈](https://github.com/weblll/boss-51job-auto-deliver/issues)

## 安装与更新

1. 在 Chrome 安装并启用 Tampermonkey（篡改猴）。
2. 打开[主脚本安装链接](https://raw.githubusercontent.com/weblll/boss-51job-auto-deliver/main/boss-zhipin-auto-greet.user.js)，由 Tampermonkey 安装。
3. 如果链接显示源码，在油猴中新建脚本，将主脚本全文粘贴并保存。
4. 刷新招聘网站，点击悬浮按钮打开面板，确认版本为 **2.16.3**。

从原仓库版本迁移时，先禁用旧脚本再安装本版。新版 namespace 已改为个人仓库地址，油猴可能将它识别为另一份脚本；不要同时启用两份。配置和去重记录仍使用原网站的 localStorage，不要清除网站数据。

## 支持范围

| 功能 | Boss 直聘 | 前程无忧 51job |
| --- | --- | --- |
| 核心操作 | 自动打招呼 | 点击网页投递简历 |
| 岗位筛选 | 薪资、黑白名单、外包、不活跃及已处理过滤 | 同左，另有国企/央企/外企筛选 |
| 城市 | 插件多选过滤、城市快捷搜索 | 网页手动选择，插件不代选 |
| 更多职位 | 下一页控件或滚动加载 | 接口采集及网页分页，受页面兼容性影响 |
| 自定义内容 | 有对应弹窗时尝试提交招呼语 | 有附言框时尝试填写 |
| VIP 自动追聊 | 可选，取决于会员权益及网站支持 | 无 |

自定义内容默认关闭；开启不代表网站一定支持，也不代表消息已送达。Boss 打招呼不等于自动发送附件简历。

## 按面板步骤使用

### 1. 设置搜索与目标城市

**Boss：** 登录并打开[职位搜索页](https://www.zhipin.com/web/geek/jobs)，在网页搜索职位并等待列表加载。在插件城市下拉中勾选投递城市，默认北京、天津、深圳。支持 14 个热门城市，也可在“编辑自定义城市”填写城市名称、代码或 `名称:9位代码`，多项用逗号分隔。

城市多选只改变投递筛选；下方快捷搜索按钮才会切换网页城市。切换会停止当前任务，新页面加载后手动开始。点击“全国搜索”不会取消插件的城市限制；要投全国，需在自定义城市中明确填写“全国”。城市未知或不匹配会跳过。备用关键词用于切换城市时搜索，不是多关键词自动轮询。

**51job：** 登录并打开[搜索页](https://we.51job.com/pc/search)，在网页“工作地点”手动选择城市，再点击网页“搜索”。城市不一定出现在地址栏。当前深度搜岗及接口翻页不能保证沿用网页城市条件，请核对职位工作地点；严格限定城市的任务暂不建议依赖此功能。

### 2. 设置岗位筛选

| 配置 | 说明 |
| --- | --- |
| 目标月薪区间 | 默认 20–30K，与岗位区间有交集就通过，含边界 |
| 岗位白名单 | 仅匹配岗位名称；留空不限制。默认偏向前端岗位，其他职业需修改 |
| 岗位黑名单 | 匹配岗位名、公司名；用逗号分隔 |
| 排除外包公司 | 按内置公司名单过滤，不保证覆盖所有外包公司 |
| 跳过不活跃职位/HR | 根据可获取的数据判断 |
| 跳过已处理职位 | 利用网页信息和本地去重记录 |
| 51job 公司性质 | 勾选后仅允许选中类别；全不勾选则不限 |

薪资示例：20–30K 可匹配 17–25K、25–40K、30–40K；不匹配 10–19K、31–40K。单端填 0 表示该端不限，两端均为 0 表示不限薪资。启用薪资筛选时，面议或无法解析的薪资会跳过。月薪以 K 为单位，多薪月份不作为月薪相乘计算。

### 3. 设置投递节奏

| 配置 | 默认值 / 行为 |
| --- | --- |
| 本次投递上限 | 50；0 表示不设本轮数量上限 |
| 本次最多处理页数 | 5，含当前页；0 表示不设上限 |
| 自动翻页 / 加载更多 | 默认开启；当前批次处理后继续加载 |
| 最小 / 最大间隔 | 8 / 15 秒 |
| 自定义招呼语 / 附言 | 默认关闭，开启后展开输入框 |

两项上限都填 0 并开启自动翻页，可以持续处理，但没有新职位、出现平台限制或手动停止时仍会结束。网站整页刷新不会自动恢复任务。插件上限不是平台每日额度，也不能突破平台额度。

自定义内容支持 `{jobName}`、`{company}`、`{salary}`。仅在网站提供对应入口时尝试填写或提交；没有入口或处理失败会记录日志，正常打招呼/投递继续。请在网站核实实际内容与送达情况。开关和内容按平台保存。

Boss 的 VIP 自动追聊为可选尝试，请按实际会员权益设置；接口探测位于诊断区域，不是正常投递必需步骤。

### 4. 采集并开始

- **采集并开始：** 读取配置，先采集职位，再依次筛选处理。
- **仅采集职位（Boss）：** 只采集当前页面的数据，不发送招呼。
- **深度搜岗（51job）：** 尝试采集更多职位；注意城市条件兼容性限制。
- **刷新列表：** 更新插件的职位列表。
- **停止：** 请求停止投递。51job 采集阶段不能立即取消的已知问题尚未修复；如需立即中断该阶段，可刷新网页，重新开始前核实投递结果。

不需要先点一次深度搜岗再开始。Boss 如果缺少完整职位数据，请点击网站“搜索”并等待加载，再采集；插件需在页面加载前启用，安装后务必刷新。

### 5. 查看进度与日志

进度展示运行状态、页数/批次、处理进度、成功、跳过和失败数量。跳过日志会说明过滤原因。点击“复制运行日志”可复制当前保留的日志用于反馈。

51job 确认出现“投递成功”提示后尝试关闭，最多三次。关闭失败会保留本条成功及去重记录，暂停后续投递；手动关闭后再开始。未确认成功时不会直接计入成功，请先在网站核实，避免重复投递。

“清除投递记录”会删除本地去重历史，可能导致重复打招呼；它不会删除网站上的沟通或投递记录。

## 常见问题与限制

- **遇到环境异常或风控：** Boss 会暂停，暂停记录至少保留 30 分钟，刷新仍有效；到期不会自动启动，也不表示限制已解除。
- **配置没有立即生效：** 修改输入后离开输入框，开始前再次确认配置；配置按网站保存在当前浏览器 localStorage。
- **看不到插件：** 确认脚本启用、站点权限允许，在受支持的搜索页面刷新后查看悬浮按钮。
- **界面或接口变化：** 可能导致采集、翻页、自定义内容或弹窗操作失效。反馈时附脚本版本、页面地址和运行日志，隐去账号凭证等敏感信息。
- **验证状态：** 本次仅更新元信息及文档，未运行构建、测试或现场投递验证；不保证网站所有场景兼容。
